# Meko Legal

This repository contains the official legal documents for **Meko**, a multi-purpose Discord bot that provides utility commands, custom messages, greetings, moderation, giveaways, fun commands, and server activity logging.

## Documents

- [Privacy Policy](PRIVACY_POLICY.md): Explains what information Meko processes, how it is used, how long it may be retained, and how users can request deletion.
- [Terms of Use](TERMS_OF_USE.md): Describes the terms, responsibilities, limitations, and conditions that apply when using Meko.

Please read the relevant documents before using the Bot.
